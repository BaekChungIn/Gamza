회원 가입이메일 주소, 비밀번호(암호화되어 저장)
프로필닉네임, 회원 종류(군인·곰신·팬), 프로필 사진(직접 올린 경우), 상태 메시지
복무 정보군종, 입대일, 전역일, 부대명(선택), 휴가·외박·외출 일정
서비스 이용 기록연인·친구 연동 정보, 편지, Q&A·일기 답변, 커뮤니티 글·댓글, MY스타 등록 정보와 응원 기록, 적금·장바구니 설정
위치(선택)‘집으로 가기’ 경로 찾기에서 현재 위치 사용을 허용한 경우에만 그 순간의 위치를 사용하며 서버에 저장하지 않아요. 위치 이용 동의는 선택이며, 동의하지 않아도 출발지를 직접 검색해 쓸 수 있어요
동의 기록약관·개인정보 동의 시각, 위치정보 동의 여부

2. 이용 목적

  • 전역일·진급일·복무율 계산 등 앱 기능 제공
  • 연인·친구 연동, 편지·질문 등 사용자 간 기능 제공
  • 커뮤니티 운영과 부적절한 게시물 관리
  • 문의 응대와 오류 수정

3. 보관 기간과 파기

회원 탈퇴 시 지체 없이 삭제해요. 법령에 따라 보관이 필요한 경우에는 그 기간 동안만 보관한 뒤 삭제해요.

4. 처리를 맡기는 곳 (위탁·외부 서비스)

  • Supabase — 회원 인증과 데이터 저장
  • GitHub Pages — 앱 화면 제공
  • 카카오맵 — 장소 검색과 지도(검색어·위치만 전달)
  • OpenStreetMap(Nominatim) — 현재 위치를 주소로 바꾸기(좌표만 전달, 위치 이용에 동의한 경우)
  • 네이버 검색 API — 상품·스타 사진과 공개 뉴스 검색(개인정보는 전달하지 않음)
  • Groq — 공개된 혜택 정보 검증(개인정보는 전달하지 않음)
  • Resend — 운영자 알림 메일 발송(사용자 정보는 포함하지 않음)

5. 제3자 제공

이용자의 개인정보를 외부에 판매하거나 제공하지 않아요. 단, 법령에 따른 요청이 있는 경우는 예외예요.

6-1. 개인정보를 지키는 방법 (안전성 확보 조치)

  • 비밀번호는 되돌릴 수 없는 방식(해시)으로 바꿔 저장해 운영자도 볼 수 없어요
  • 모든 통신은 HTTPS로 암호화돼요
  • 데이터베이스는 '본인 것만 읽고 쓰기' 규칙(행 수준 보안)으로 다른 사람의 정보에 접근할 수 없어요
  • 로그인 실패가 반복되면 잠시 로그인을 막아요
  • 외부 서비스 열쇠(API 키)는 앱 화면이 아니라 서버에만 보관해요
